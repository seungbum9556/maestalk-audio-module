# 전달 모듈 0.1.0의 비교 기준

이 문서는 모델 선정 당시의64ms 평가 기록이다. 현재0.3.0의16ms 지표·음향 시작점 후보·악보 보조 기능은 [OFFLINE_030.md](OFFLINE_030.md)를 따른다. 아래의 시작점 미구현은0.1.0 당시 상태다.

선정일: 2026-11-26. 이 모듈은 녹음 후 분석용 **SwiftF0 0.3.0 + FCPE DDSP-200K**를 포장했다. 포장 자체를 정확도 개선으로 계산하지 않는다. 외부의 새 모델 학습은 하지 않았다.

Swift의 유효한 자체 점수≥0.9이면 유지한다. FCPE 점수≥0.8이며 Swift가 없거나 점수<0.9이면 FCPE를 선택한다. Swift의 유성 임계값은0.5, FCPE 내부 디코딩 임계값은0.006이다. 점수 두 개를 같은 확률로 비교하지 않는다. Hz 평균이나 무음 구간의 임의 보간은 하지 않는다.

선택4녹음(Jupiter 바이올린/Maria 첼로/Pirates 첼로/MusicNet2217 첼로)×3조건에서 임계값120조합을 비교했고, 다른5녹음(Jupiter 첼로/Schubert 첼로/Brahms 바이올린/MusicNet2298 첼로/Jesus 바이올린)×3조건으로 고정값을 재확인했다. 모두 이전 개발에서도 사용한 녹음으로 새 독립 검증이라고 부르지 않는다. 모델 사전학습과 녹음의 중복도 미확인이다.

## 평가 기준

- `baseline_metrics.csv`: 선정 모델의27조건. 원본, 진폭−12dB(약1/4), 고정 시드SNR10dB.
- 일치율: 정답 유성 프레임 중±50cent 이내 비율. 누락도 분모에 포함.
- pitchF1: `2*correct/(reference_voiced+predicted_voiced)`. 오음·무음 오검출을 반영.
- 옥타브 오류: 오음 중1200cent 정수배±50cent에 드는 부분집합.
- 평가 격자:0.032초부터64ms 간격. 모듈 출력의16ms 격자와 구분.
- 겹치는 정답 음표는 단일 음높이 평가에서 제외. `core_accuracy`는 시작/끝50ms 제외.
- `whole_notes_without_correct_pitch`는 음표 구간에 정답을 한 번도 얻지 못한 개수로, 음 시작점 검출 누락과 구분한다.
- URMP 연속F0 정답과 TRIOS/MusicNet 정렬 명목MIDI 정답을 구분한다. MIDI를Hz로 바꾼 값은 연주 중 비브라토/음정 편차의 실측F0가 아니다.
- `comparison_vs_previous.csv`: 파형 해시·정답·시각을 맞춘 기존 CREPE full+Swift와20조건 비교. 정답+222/손실75프레임이 함께 있었다. 처리 지연 비교는 아니다.

## 어려운 구간과 미완료 기능

MusicNet2217(바흐 첼로 모음곡3번 Prelude)과2298(4번 Gigue)은 각각 처음30초이며 음표 길이 중앙값은162.54/150.93ms다. 원본 일치율61.66/60.51%, 경계50ms 제외70.71/78.95%로 남은 오류가 크다. 모델 오류와 주석 정렬·실제 음향 전환 각각의 원인은 별도 검수 없이 확정하지 않는다.

Basic Pitch도 실제27조건에서 시작점/음표를 비교했으나 추가·누락이 많아 미채택했다. 이번 모듈은 `onsets: null`을 반환한다. RMS·Chroma 출력이 있어도 시작점 기능이 완성된 것은 아니다. 실제 악기 상대음량의 정답 평가, 새 곡·연주자 검증, 스트리밍·마이크·3입력 성능은 남은 작업이다.

## 녹음 출처와 재검증 준비

- [URMP](https://labsites.rochester.edu/air/projects/urmp/): 파트별 `AuSep_*.wav`, 연속 `F0s_*.txt`, `Notes_*.txt`. Jupiter/Maria/Pirates/Jesus 각각 처음30초. 혼합음이나 자동 분리 결과를 사용하지 않았다.
- [TRIOS](https://zenodo.org/records/6797837): 실제 분리 WAV와 수작업 정렬MIDI. Schubert 첼로 전체53.125초, Brahms 바이올린 전체43초. 합성 `_syn.wav` 제외.
- [MusicNet](https://zenodo.org/records/5120004):2217/2298 오디오와 샘플 기준 음표 정답. 두 파일 각각0–30초. 명목 음표 DTW 정렬이라는 평가 한계를 유지한다.

실제 녹음 원본은 이 ZIP에 포함하지 않는다. 먼저 공개 자료의 사용 조건을 확인하고 파트별 WAV와 해당 정답을 확보한다. 마이크·거리·게인·AGC·연주자 정보가 확인되지 않은 녹음은 미확인으로 기록한다. 데이터로 설정을 바꾸면 개발 자료로 표시하고 다음 검증에는 다른 자료를 쓴다.
